AI Chat

Answers read the code the PR has

AI Chat now reads a review checkout: a git worktree at the reviewed commit, kept in the data directory. The branch you have checked out doesn't matter.

  • Files the PR didn't change come from its base branch.
  • Reviewing uncommitted work? It still reads your working tree.
  • If a checkout fails, the chat says so before it answers.

Review interface

Read one layer at a time

Set Show layers to one at a time. The canvas then shows the overview or one layer. Move between them with the rail, or press j and k.

  • A link into a layer opens that layer.
  • Marking a layer reviewed doesn't jump to the next one.
  • The default, all, keeps the canvas as one page.

Sharing

Keep canvases local when you need to

Two switches in pr-review.config.yml. One stops publish from commenting on the PR. The other keeps the canvas out of comments you post.

  • Anyone can override either one in .pr-review/settings.yml.
  • Posting comments and reviews from the page still works.

A clearer command line

doctor prints a checklist. --help shows each command in its own block. serve opens your browser.

  • Breaking: pass doctor --json for the old JSON line.
  • serve --no-open or CI keeps the browser closed.
  • --chat-agent and --chat-model replace --agent and --model.
